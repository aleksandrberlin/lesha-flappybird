# Flappy Lesha 🎮

8-битный клон Flappy Bird на чистом JavaScript. Вместо птички — пиксельное лицо
с фотографии, а в роли врагов — гигантские бутылки кока-колы и Кэти Перри,
которая периодически пролетает через экран.

![Титульный экран](docs/title.png)
![Геймплей](docs/gameplay.png)

## Как запустить

Игра не требует сборки и зависимостей — это обычная статическая страница.

```bash
# просто открыть файл
open index.html            # macOS
xdg-open index.html        # Linux

# или поднять локальный сервер
python3 -m http.server 8000
# затем http://localhost:8000
```

## Геймплей

* **Бутылки колы** — это «трубы»: пролетай в зазор между верхней и нижней бутылкой.
  Каждая пройденная пара даёт очко.
* **Кэти Перри** появляется каждые несколько очков (и минимум раз в ~7 секунд),
  летит навстречу по синусоиде и роняет нотки. Столкновение — смерть,
  успешный облёт — дополнительное очко.
  Скорость её подлёта подбирается так, чтобы встреча случилась в свободном
  коридоре между бутылками, а не внутри зазора — так её всегда можно обойти.
* Сложность растёт со счётом: скорость с 1.75 до 2.95, зазор со 148 до 112 px.
* Медали на экране проигрыша: бронза с 10 очков, серебро с 20, золото с 40.
  Рекорд хранится в `localStorage`.

## Структура

```
index.html            разметка и порядок подключения скриптов
css/style.css         оформление страницы вокруг канваса
src/assets-data.js    сгенерированные спрайты (лицо в base64, Кэти, бутылка)
src/font.js           растровый шрифт 5x7 и отрисовка текста
src/audio.js          чиптюн-звуки на WebAudio (квадратная волна + шум)
src/game.js           игровой цикл, физика, враги, экраны
assets/hero.png       спрайт лица 32x32
tools/make_assets.py  генерация спрайтов из фотографии
tools/smoke-test.js   headless-проверка игры через Playwright
```

Всё рисуется на `<canvas>` 320x480 с отключённым сглаживанием и целочисленным
масштабированием — поэтому картинка остаётся чёткой пиксельной на любом экране.

## Спрайт лица

Лицо вырезается из фотографии, уменьшается до 32x32, квантуется до 16 цветов,
обрезается по эллипсу-голове и обводится тёмным контуром:

```bash
pip install pillow
python3 tools/make_assets.py путь/к/фото.jpg
```

Скрипт перезаписывает `assets/hero.png` и `src/assets-data.js`. Исходная
фотография в репозиторий не попадает — только готовый пиксельный спрайт.
Положение головы на фото задаётся константами `HEAD`, `HEAD_RX`, `HEAD_RY`
в начале скрипта.

## Тесты

```bash
npm i playwright
python3 -m http.server 8777 &
node tools/smoke-test.js
```

Автопилот играет ~45 секунд и проверяет, что нет ошибок в консоли, счёт растёт,
Кэти появляется и её можно облететь, а экран проигрыша работает.
